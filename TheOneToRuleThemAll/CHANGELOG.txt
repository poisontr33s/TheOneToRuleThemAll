0.3.1-combined — 26 October 2026

- Combines Astra's actual-key previews and Blood profiles with Claude's
  clearer messages, Toy Box pickup and partial-Undo reporting.
- Failed Apply uses strict rollback. If an original button cannot be restored,
  its backup stays available for Undo instead of falsely reporting completion.
- Adds regression tests for unavailable original items, pets and equipment sets.
- Keeps physical key counts separate from available attacks in Rogue labels.
- One installable build on combined; actual WoW client checks remain open.

0.3.0-astra — 26 October 2026

- Adds San'layn and Deathbringer Blood layouts for Yipyep's Shed Assymetry.
  The existing class/Blood talent foundation is retained; no talent, equipment
  or keybinding changes are performed.
- Blood places individual spells on main-bar slots 1–9 and learned utility
  spells on fixed Bar 2 slots. Reaper's Mark has its own Deathbringer button.
  Unlearned optional slots are preserved, including Mind Freeze on slot 7.
- Blood has no Rogue Stealth/Dance mirroring and no generated burst macros.
  Temporary Vampiric Strike/Exterminate overrides keep their base buttons.
- Preview selects the compatible Blood hero profile without applying it.
  Layout help lists only layouts provided by each profile.
- Adds Blood placement, failure recovery, reload/Undo and UI regression tests.
- Existing Rogue policies are unchanged. Live WoW validation remains pending.

0.2.2-astra — 25 October 2026

- The preview shows actual built-in keybindings beside each main-bar and Bar 2
  ability, including both bound keys, mouse buttons and unbound slots.
- Compact shows Alt chords for the user's bindings and identifies conflicts.
- Macro buttons describe their localized abilities and conditional alternatives.
- Binding changes refresh the open preview. No new bindings or automatic casts.
- Macro bodies, placements, damage priorities and Undo behavior are unchanged.
- Separate Astra test build from main; live WoW testing remains outstanding.

0.2.2-claude — 25 October 2026 (claude branch)

- Undo restores everything it can. An item, battle pet or equipment set that is
  no longer available is cleared and named in chat, instead of stopping Undo
  half-way and leaving it stuck. Toys are picked up from the toy box if needed.
- Messages name the bar and slot (for example "Action Bar 2 slot 3") and the
  kind of action in words. Alt conflicts show the binding's in-game name.
- Action Bar 2 is listed on one chat line after Apply and in preview.
- /tor status shows the specialization by name and the saved setup's state in
  words. Remaining internal wording ("policy", "routine class buttons",
  "tested module", "remains passive", "prerequisites") is gone from player text.
- The unused IsPlayerSpell and GetActionBarPage fallbacks are removed; the tests
  keep both globals absent.
- Macros, slot layout and the simulated priorities are unchanged.

0.2.1 — 25 October 2026

- Uses C_SpecializationInfo; obsolete global functions are absent from the tests.
- Removes unsupported flyout handling. Setup rejects an affected flyout before
  picking up existing macros or placing actions.
- Simulation/model text appears only under Show details, not in Apply chat.
- Lists every affected Bar 2 slot and localized ability, and explains what
  existing keys will cast after Apply. This appears in the window and chat.
- Uses localized class names, Status and previous setup in the player interface.
- Frame mocks accept only the nine supported events. 136/136 mock tests pass.
- The companion research archive now contains this same 0.2.1 addon. Simulation
  data and the 0.1.0 comparison report retain their original historical results.

0.2.0 — 25 October 2026

- /tor opens a setup panel with profile/layout preview, readiness, Apply and Undo.
- /tor check inspects prerequisites without touching bars, macros or saved data.
- Repeated Undo no longer replays a restored snapshot over later manual changes.
- New snapshots also guard the selected saved talent loadout and Starter Build
  status. Older snapshots remain recoverable with the limitation shown explicitly.
- Existing Subtlety and Assassination policies/macros are unchanged. Other classes
  remain passive; no additional DPS gain or new class support is claimed.
- Validation uses mock WoW APIs/widgets. Live rendering and casting remain untested.

0.1.0 — initial Rogue release

- Reversible profile setup, character-scoped macros and per-character backups.
- Standard and Compact layouts; native Rogue Stealth/Dance bar mirroring.
- Fixed-gear Rogue comparisons supplied in the separate simulation report.
