THE ONE TO RULE THEM ALL — DEVELOPMENT

SCOPE

Method.gg's latest verified Mythic+ builds are the talent standard.
Keep the guide's exact imports, labels, patch and update date. Put a clear
source recommendation first; preserve published alternatives where needed.
Check current primary sources when changing abilities or macros.
No new talent builds, DPS rankings or simulation requirements.
Keep code readable and player text short.

FILES

Core.lua handles profiles, checks, placement and Undo.
NativeBar.lua checks the visible main bar and current form.
Modules/Standard.lua places learned spells and healer mouseover macros.
Controls.lua reads existing keys. UI.lua shows the preview and setup actions.
TalentBrowser.lua copies published Mythic+ codes for manual import.

Edit tools/class_data/*.json, then run:
python3 tools/generate_standard_profiles.py

The generator validates all specs and records source hashes. Only current
Method Mythic+ builds belong in the source and StandardData.lua.
The TOC determines which Lua files are loaded and packaged.

PLACEMENT

Main bar: core spells. Bar 2: utility. Bar 3: extra spells, then racials
in slots 10–12. Keep positions fixed; skip unlearned optional spells.
Use base spell buttons so temporary combat replacements can come and go.
Healer Mouseover is an explicit layout using localized spell names.

Druid requires the spec's form; only that form's main bar changes.
Rogue setup requires leaving Stealth/Shadow Dance and leaves that bar alone.
A row's mainButton identifies the visible button even on a form page.

Profile fields: id, class, spec, specName, label, layouts, evidence, build.
build(api, layout, enforce) returns rows, macros, skipped and lines.
Rows contain slot, optional mainButton, and an action record.
Use api.spell(id) or api.macro(name, body); register macros in plan.macros.
Preview is read-only. All writes go through guarded Apply or Undo.
Preserve backup recovery even when a profile is retired.
